# Maya Blog ✦

ब्यूटीफुल best look, logo ko apni और आकर्षित करना

## 🌟 Features

- **सुंदर डिज़ाइन** — मॉडर्न और आकर्षक UI
- **डार्क मोड** — लाइट और डार्क थीम सपोर्ट
- **रेस्पॉन्सिव** — मोबाइल, टैबलेट और डेस्कटॉप पर परफेक्ट
- **हिंदी ब्लॉग** — हिंदी में गुणवत्तापूर्ण कंटेंट
- **कैटेगरी फ़िल्टर** — विषय के अनुसार पोस्ट ढूंढें
- **न्यूज़लेटर** — सब्सक्राइब करें नई पोस्ट के लिए

## 📄 Pages

- **होम** (`index.html`) — हीरो सेक्शन, फीचर्ड और लेटेस्ट पोस्ट
- **ब्लॉग** (`blog.html`) — सभी पोस्ट कैटेगरी फ़िल्टर के साथ
- **पोस्ट** (`post.html`) — ब्लॉग पोस्ट पेज
- **हमारे बारे में** (`about.html`) — टीम, मिशन और मूल्य
- **संपर्क** (`contact.html`) — कॉन्टैक्ट फ़ॉर्म और FAQ

## 🚀 Getting Started

Simply open `index.html` in your browser, or deploy to GitHub Pages.

## 🛠 Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript
- Google Fonts (Poppins + Noto Sans Devanagari)
