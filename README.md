# unmoney

> Your money, simplified. A modern SaaS personal finance management tool.

## Features

- **Smart Dashboard** — Real-time overview of your balance, income, expenses, and savings
- **Transaction Tracking** — Search, filter, and categorize all your transactions
- **Budget Planning** — Set spending limits by category with visual progress tracking
- **Deep Analytics** — Beautiful charts showing income vs expenses, spending breakdown, and savings trends
- **Responsive Design** — Works beautifully on desktop, tablet, and mobile
- **Dark Landing Page** — Stunning marketing page with features, pricing, and testimonials

## Tech Stack

- **React 19** + **Vite** — Fast development and builds
- **Tailwind CSS 4** — Utility-first styling
- **React Router** — Client-side routing
- **Chart.js** + **react-chartjs-2** — Interactive charts
- **Lucide React** — Beautiful icons

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Pages

| Route | Description |
|-------|-------------|
| `/` | Landing page with hero, features, pricing, testimonials |
| `/login` | Sign in page |
| `/signup` | Create account page |
| `/dashboard` | Main dashboard with financial overview |
| `/transactions` | Transaction list with search and filters |
| `/budgets` | Budget management with progress bars |
| `/analytics` | Charts and insights (income vs expenses, category breakdown) |
| `/settings` | Profile, notifications, security, connected accounts |
