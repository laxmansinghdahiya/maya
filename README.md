# Maya

ब्यूटीफुल best look, logo ko apni और आकर्षित करना

## Local Development

### Prerequisites

- Ruby (>= 2.7)
- Bundler (`gem install bundler`)

### Setup

```bash
bundle install
bundle exec jekyll serve
```

Then open [http://localhost:4000](http://localhost:4000) in your browser.
